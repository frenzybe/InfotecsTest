# Timescale API

WebAPI приложение для обработки timescale данных (CSV) и вычисления интегральных показателей. Разработано в рамках тестового задания.

## Стек технологий и архитектурные решения
* **.NET 8 / Minimal APIs**: легковесная и быстрая маршрутизация.
* **EF Core & PostgreSQL**: использование `ExecuteDeleteAsync` для быстрого удаления без аллокаций.
* **Сверхбыстрый парсинг**: чтение и валидация CSV "на лету" с использованием `ReadOnlySpan<char>` для минимизации нагрузки на Garbage Collector.
* **FluentValidation**: строгая декларативная валидация данных.
* **Паттерн Result**: обработка бизнес-ошибок без использования дорогостоящих исключений (`Exceptions`).

## Быстрый запуск (Docker)
Проект настроен для моментального запуска через Docker Compose.

1. Склонируйте репозиторий.
2. Откройте терминал в корневой папке и выполните:
   `docker compose up --build -d`
3. Откройте Swagger для тестирования методов: `http://localhost:8080/swagger`
